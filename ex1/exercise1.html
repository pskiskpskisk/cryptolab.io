How the Vigenère Cipher Works

The Vigenère cipher is a method of encrypting alphabetic text by using a series of interwoven Caesar ciphers based on the letters of a keyword.

Algorithm:

For each letter in the plaintext:

1. Find the numeric position (A=0, B=1, ..., Z=25) of the plaintext letter

2. Find the numeric position of the corresponding key letter

3. For encryption: Add the two numbers modulo 26

4. For decryption: Subtract the key number from the ciphertext number modulo 26

5. Convert the result back to a letter

Example: Message: "HELLO", Key: "KEY"

Key repeated: "KEYKE"

H (7) + K (10) = R (17)

E (4) + E (4) = I (8)

L (11) + Y (24) = J (9) [35 mod 26 = 9]

Result: "RIJ"

How the Playfair Cipher Works

The Playfair cipher uses a 5x5 matrix of letters constructed from a keyword. The letters I and J are usually combined.

Encryption Rules:

1. Split the message into digraphs (pairs of letters)

2. If both letters are in the same row: replace with letters to the right (wrapping around)

3. If both letters are in the same column: replace with letters below (wrapping around)

4. Otherwise: form a rectangle and replace with letters on the same row but opposite corners

Example Matrix (Key: "PLAYFAIR"):

P L A Y F

I R B C D

E G H K M

N O Q S T

U V W X Z

Example: "HI" -> "DE" (same column)

"DE" -> "HI" (same column, decryption)

How the Affine Cipher Works

The Affine cipher is a type of monoalphabetic substitution cipher where each letter in an alphabet is mapped to its numeric equivalent, encrypted using a simple mathematical function, and converted back to a letter.

Encryption Formula:

E(x) = (ax + b) mod 26

Decryption Formula:

D(x) = a⁻¹(x - b) mod 26

Where a⁻¹ is the modular multiplicative inverse of a modulo 26

Example: a=5, b=8

Encrypt "A" (0): (5×0 + 8) mod 26 = 8 → "I"

Encrypt "T" (19): (5×19 + 8) mod 26 = (95+8) mod 26 = 103 mod 26 = 25 → "Z"

Decrypt "I" (8): a⁻¹ = 21 (since 5×21 mod 26 = 105 mod 26 = 1)

21×(8-8) mod 26 = 0 → "A"
